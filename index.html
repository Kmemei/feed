Gemini 现在的 API 只喂文件里那几页，钱也只按那几页算

11 月 18 日上了文件切片，PDF、Word、PPT、Excel/ODS 可以直接传，然后指定页码、工作表里的单元格区域、音视频的时间段，还能挑只要提取出的文字、还是连页面渲染图一起要。官方文档给了档位——一页按中等分辨率约 560 tokens，低 280、高 1120。一本 200 页的报告整份喂是 11 万 tokens，只看其中四页就两千出头。

视频同理，按秒切（`start_offset` 到 `end_offset`），默认 1 fps，长片只想看某几分钟的话省得最狠；音频能单独要转写不要波形。

切片只管「读多少、付多少」，文件本身还是整份走 Files API 上传，上限一点没松：单文件 50 MB、PDF 1000 页、Office 2000 页，传上去留 48 小时。参数挂在 Interactions API 的 document 块上（`processing` 里的 `start_page`、`end_page`、`content_layers`、`resolution`），OpenAI 兼容转发不支持，得直连 Gemini。切片只决定模型读什么，文件本身该给 Google 还是给了。
